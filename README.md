# Mini-Annapurna: A Python-Only Cycle-Accurate Simulator & Compiler for a Systolic AI Accelerator

**Version 1.0** | **License: MIT**

## Project Elevator Pitch

Mini-Annapurna is an open-source, hardware-free reference stack that shows how PyTorch operations are lowered to a custom systolic-array ISA, scheduled, and executed under a cycle-accurate performance model.  **compiler construction**, **hardware–software co-design**, and **performance analysis**.
